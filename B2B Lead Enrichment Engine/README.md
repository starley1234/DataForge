# B2B Lead Enrichment Engine (Россия)

Комплексная система для поиска, обогащения и валидации контактов (Email, телефоны, профили, URL) лиц, принимающих решения (ЛПР) на предприятиях России.

## Архитектура системы

```
[Реестры ЮЛ (ЕГРЮЛ / DaData / Rusprofile)] 
       │ (ИНН, ОГРН, ОКВЭД, Выручка, Сайт, ФИО Гендиректора)
       ▼
[Краулинг сайтов и профессиональных сетей (TenChat, LinkedIn)]
       │ (ФИО, Должность, URL профиля, Корпоративный домен)
       ▼
[Генерация и поиск контактов (Email Permutations, Scraper)]
       │ (Транслитерация ГОСТ/ISO, подбор шаблонов корпоративных почт)
       ▼
[Валидация (DNS MX, Синтаксис, SMTP Handshake, E.164 телефоны)]
       │ (Только валидные и верифицированные контакты)
       ▼
[Хранение и Экспорт (SQLite / PostgreSQL / CSV / Excel / Web UI)]
```

## Источники данных

1. **ЕГРЮЛ ФНС РФ (`fns_source.py`)**: Прямой сбор официальных данных без платных API (электронные выписки ФНС в PDF):
   - Полное и краткое наименование, ОГРН, КПП, регион и адрес.
   - ФИО и должность первого лица (Генеральный директор, Президент).
   - Официальный E-mail и домен, зарегистрированный в налоговой.
   - Основной ОКВЭД.
2. **Краулер сайтов и контактов (`scraper.py`)**:
   - Поиск телефонов, корпоративных email, профилей соцсетей (Telegram, VK, LinkedIn, TenChat).
   - Извлечение команды и руководителей со страниц `/contacts`, `/about`, `/team`, `/management`.
3. **Генератор и валидатор email (`email_generator.py`, `validator.py`)**:
   - Транслитерация по ГОСТ/ISO и генерация 11 распространенных шаблонов.
   - DNS MX резолвинг и отсеивание недействительных почтовых доменов.
4. **DaData API & Rusprofile** (опционально при наличии `DADATA_API_KEY`).

## Примеры использования CLI

### 1. Запуск демонстрационного сбора и экспорта в Excel и CSV:
```bash
python3 cli.py --demo --export-csv leads.csv --export-excel leads.xlsx
```

### 2. Генерация корпоративных email по ФИО и домену:
```bash
python3 cli.py --generate-email "Иванов Иван Иванович" "yandex.ru"
```

### 3. Проверка и валидация email / телефона:
```bash
python3 cli.py --check-email "i.ivanov@yandex.ru"
python3 cli.py --check-phone "8 (495) 739-70-00"
```

## Запуск Web-интерфейса

```bash
uvicorn web_app:app --host 0.0.0.0 --port 8080
```
После запуска доступен веб-интерфейс:
- Просмотр всех собранных компаний и ЛПР.
- Экспорт в CSV / Excel в один клик.
- Интерактивный генератор корпоративных email-шаблонов.
- Инструмент валидации контактов.
