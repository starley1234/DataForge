# B2B Lead Enrichment & Intelligence Engine (Россия / СНГ)

**B2B Lead Enrichment Engine** — комплексная производственная платформа для автоматического поиска, обогащения, генерации и валидации контактных данных лиц, принимающих решения (ЛПР: Генеральные директора, Президенты, Коммерческие, Технические и Финансовые директора) предприятий Российской Федерации.

Платформа решает ключевую задачу B2B-продаж и маркетинга: **получение прямых, верифицированных корпоративных контактов ЛПР без ручного поиска и без зависимости от дорогостоящих зарубежных сервисов** (ZoomInfo, Apollo, Cognism), адаптируя все алгоритмы под российскую специфику (ЕГРЮЛ, стандарты транслитерации ГОСТ/ICAO, домены .RU/.РФ, мобильные DEF-коды РФ).

## Ключевые возможности

1. **Прямая интеграция с официальным ЕГРЮЛ ФНС РФ (`fns_source.py`)**:
   - Автоматический поиск по ИНН (10 или 12 знаков), ОГРН или наименованию.
   - Извлечение ФИО руководителя и должности напрямую из JSON-реестра и выписок PDF без платных API-ключей.
   - Определение основного ОКВЭД, региона и официального адреса.

2. **Domain Discovery Engine (`domain_finder.py`)**:
   - Автоматическое нахождение корпоративного сайта компании по названию и региону.
   - Исключение агрегаторов и реестров (Rusprofile, Spark, Checko, Sbis, HH, 2GIS).

3. **Краулер контактных данных и команды (`scraper.py`)**:
   - Поиск страниц руководства (`/about`, `/team`, `/management`, `/o-kompanii`, `/kontakty`).
   - Извлечение прямого состава топ-менеджеров с классификацией (C-Level, Director, Head).
   - Сбор соцсетей организации (Telegram, VKontakte, TenChat, LinkedIn, HeadHunter).
   - Сверка реквизитов (ИНН, ОГРН, КПП) на сайте компании для верификации источника.

4. **Генератор корпоративных Email (`email_generator.py`) и Транслитерация (`translit.py`)**:
   - Поддержка 15 наиболее распространенных российских и международных корпоративных формул (`{f}.{last}`, `{last}.{f}`, `{first}.{last}`, `{last}`, `{first}`, `{last}_{f}` и др.).
   - Двойная транслитерация (ГОСТ 7.79-2000 Система Б + международный ICAO).
   - **Pattern Learning**: автоматическое определение паттерна адресов компании по найденным контактам и приоритизация до 98% уверенности.
   - Определение пола и составление деловых обращений ("Уважаемый Иван Иванович!").

5. **Валидация контактов (`validator.py`)**:
   - Потокобезопасный LRU-кэш DNS MX-записей для многократного ускорения пакетной обработки.
   - База одноразовых (disposable) и публичных бесплатных почтовых провайдеров.
   - Проверка номеров телефонов через библиотеку `phonenumbers` с разделением на мобильные (DEF 9xx), офисные (ABC 495/812) и бесплатные линии 8-800.

6. **Пакетная обработка (Batch Processing) (`batch_processor.py`)**:
   - Фоновая асинхронная обработка списков предприятий из файлов CSV или Excel (.xlsx).
   - Отслеживание статуса и процентного прогресса в реальном времени.

7. **Экспорт данных и CRM-интеграция (`exporter.py`)**:
   - Стилизованный **Excel (.xlsx)** с цветовым кодированием статусов валидации и автоподбором колонок.
   - **CSV** с кодировкой UTF-8 с BOM (корректно открывается в Microsoft Excel на Windows).
   - Готовый экспорт для **amoCRM** (сделки и контакты) и **Битрикс24** (лиды).
   - Генератор персонализированных B2B холодных писем (партнерство, продажи, демо-доступ).

## Быстрый старт

### 1. Установка зависимостей

```bash
cd "B2B Lead Enrichment Engine"
pip install -r requirements.txt
```

### 2. Конфигурация (.env)

Скопируйте пример настроек:
```bash
cp .env.example .env
```
При необходимости укажите PostgreSQL или API-ключ DaData. По умолчанию система работает "из коробки" на локальной БД SQLite.

### 3. Запуск тестов

Проект покрыт 38 автоматическими тестами `pytest`:
```bash
pytest -v
```

## Примеры работы через CLI (`cli.py`)

Интерфейс командной строки поддерживает интерактивные цветные таблицы и прогресс-бары:

### 1. Демонстрационное обогащение эталонной базы компаний:
```bash
python3 cli.py --demo
```

### 2. Сводная аналитика текущей базы:
```bash
python3 cli.py --stats
```

### 3. Поиск и обогащение компании по ИНН:
```bash
python3 cli.py --inn 7707083893
```

### 4. Генерация корпоративных вариантов Email:
```bash
python3 cli.py --generate-email "Иванов Иван Иванович" "sberbank.ru"
```

### 5. Проверка Email и номера телефона:
```bash
python3 cli.py --check-email "pr@yandex-team.ru"
python3 cli.py --check-phone "+7 (495) 739-70-00"
```

### 6. Генерация текста холодного письма для конкретного ЛПР:
```bash
python3 cli.py --outreach 1
```

### 7. Экспорт базы в Excel и CRM:
```bash
python3 cli.py --export-excel leads.xlsx --export-amocrm leads_amo.csv --export-bitrix24 leads_b24.csv
```

### 8. Запуск Web-сервера через CLI:
```bash
python3 cli.py --serve --port 8080
```

## Запуск Web-интерфейса и Dashboard

Запуск ASGI-сервера:
```bash
uvicorn web_app:app --host 0.0.0.0 --port 8080
```

После запуска в браузере доступна полнофункциональная веб-панель:
1. **База контактов (CRM)**:
   - Интерактивная таблица всех сохраненных ЛПР.
   - Мгновенная фильтрация по региону, роли, статусу Email и уровню доверия.
   - Копирование email/телефона в один клик.
   - Карточка ЛПР с возможностью редактирования, заметок и генерации персонализированного холодного письма.
2. **Аналитика и KPI**:
   - Графики Chart.js: распределение по должностям, топ-регионы РФ, отраслевая структура базы (ОКВЭД).
3. **Поиск и Обогащение**:
   - Поиск по ИНН / названию с анимированным индикатором выполнения этапов.
4. **Пакетная обработка (Batch)**:
   - Загрузка реестров в `.xlsx` или `.csv`, фоновая обработка и мониторинг прогресса.
5. **Инструменты валидации**:
   - Живой генератор email-паттернов, валидатор телефонов с определением оператора и MX-чекер.
6. **Экспортный центр**:
   - Выгрузка в Excel, CSV, amoCRM, Битрикс24 и JSON в 1 клик.

## REST API Документация

Интерактивная документация Swagger UI доступна по адресу: `http://localhost:8080/docs`

### Основные эндпоинты:

| Метод | URL | Описание |
|---|---|---|
| `GET` | `/health` | Проверка состояния сервиса (Health check) |
| `GET` | `/api/stats` | Сводная аналитика (число компаний, ЛПР, доли статусов) |
| `GET` | `/api/leads` | Получение списка лидов с пагинацией и фильтрами |
| `GET` | `/api/leads/{id}` | Детальная карточка контакта ЛПР |
| `PUT` | `/api/leads/{id}` | Обновление статуса в CRM, телефона, email или заметок |
| `DELETE` | `/api/leads/{id}` | Удаление контакта из базы данных |
| `POST` | `/api/enrich/real` | Поиск и обогащение организации по ИНН / названию |
| `POST` | `/api/enrich/domain` | Прямое обогащение организации по сайту / домену |
| `POST` | `/api/batch/upload` | Загрузка файла CSV/Excel для фонового обогащения |
| `POST` | `/api/batch/start` | Запуск пакетной задачи по перечню ИНН |
| `GET` | `/api/batch/status/{task_id}` | Прогресс и статус фоновой пакетной задачи |
| `POST` | `/api/tools/generate-email`| Генерация корпоративных вариантов почты по ФИО |
| `POST` | `/api/tools/verify-email` | Полная валидация email (DNS MX, disposable) |
| `POST` | `/api/tools/verify-phone` | Нормализация телефона в E.164 и определение оператора |
| `POST` | `/api/tools/outreach-draft`| Генерация текста холодного B2B-письма |
| `POST` | `/api/leads/reverify` | Массовая перепроверка MX всех email в базе |
| `GET` | `/api/export/excel` | Скачивание форматированного файла Excel (.xlsx) |
| `GET` | `/api/export/csv` | Скачивание CSV файла в кодировке UTF-8 с BOM |
| `GET` | `/api/export/amocrm` | Скачивание файла импорта сделок и контактов в amoCRM |
| `GET` | `/api/export/bitrix24` | Скачивание файла импорта лидов в Битрикс24 |

## Развертывание в Production (Docker & PostgreSQL)

### Запуск через Docker Compose:

```bash
docker-compose up -d --build
```
Это запустит:
- Контейнер `web` на базе Python 3.11 с 4 рабочими процессами Uvicorn.
- Контейнер `db` с базой данных PostgreSQL 16 с сохранением данных в Docker Volume.
- Автоматические проверки работоспособности (Healthcheck).
