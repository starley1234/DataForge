# AI Contacts Hub & Harvester

Автоматизированная система сбора, парсинга и визуализации базы действующих email-контактов исследователей и инженеров в области искусственного интеллекта (AI/ML/LLM/CV/NLP).

## 📁 Структура проекта

```
.
├── src/
│   ├── harvester.py         # Модуль сбора препринтов arXiv и извлечения email авторов
│   └── app.py               # Flask REST API сервер и бэкенд
├── web/
│   ├── templates/
│   │   └── index.html       # Наглядный веб-интерфейс (дашборд, фильтры, таблица)
│   └── static/
│       ├── app.js           # Логика работы UI, поиск, пагинация, запуск сбора
│       └── style.css        # Стили интерфейса
├── data/
│   ├── ai_contacts.db       # База данных SQLite с контактами
│   └── ai_contacts.csv      # CSV-файл для выгрузки в Excel/Google Sheets
├── requirements.txt         # Зависимости Python
└── README.md                # Документация проекта
```

## 🚀 Запуск проекта

1. **Запуск сбора контактов в терминале:**
   ```bash
   python3 -m src.harvester --limit 100
   ```

2. **Запуск веб-интерфейса (UI):**
   ```bash
   python3 src/app.py
   ```
   После запуска веб-интерфейс доступен по адресу: `http://localhost:5000`

## 📊 Возможности UI:
* **Метрики в реальном времени:** отображение общего числа email и уникальных доменов.
* **Поиск и фильтрация:** мгновенный поиск по имени, email, организации, теме или названию публикации.
* **Экспорт:** скачивание актуальной базы в формате CSV в один клик.
* **Запуск сбора из UI:** возможность запускать фоновый парсинг новых публикаций прямо из модального окна в браузере.
